参赛者需要实现如下 Triton Python 接口：

```python
def run_kernel(x, w_gate, w_up, b_gate, b_up, y, M: int, K: int, N: int):
    # launch your Triton kernel here
    return
```

参数顺序必须保持不变。`x`、`w_gate`、`w_up`、`b_gate`、`b_up` 为只读输入，`y` 为输出 tensor。函数返回值会被忽略，必须在函数内部将结果写入 `y`。
