参赛者需要实现如下 CUDA 接口：

```cpp
#include <cuda_bf16.h>
#include <stdint.h>

extern "C" void run_kernel(
    const __nv_bfloat16* x,
    const __nv_bfloat16* w_gate,
    const __nv_bfloat16* w_up,
    const float* b_gate,
    const float* b_up,
    __nv_bfloat16* y,
    int64_t M,
    int64_t K,
    int64_t N
);
```

参数顺序必须保持不变。`run_kernel` 内部需要自行计算 grid 与 block，并 launch CUDA kernel 完成计算。只读输入指针不得被修改，输出指针 `y` 必须被完整覆盖。
