参赛者需要实现如下 TileLang Python 接口：

```python
real_kernel = None

def run_kernel(x, w_gate, w_up, b_gate, b_up, y, M: int, K: int, N: int):
    global real_kernel
    # build or reuse your TileLang kernel, then launch it here
    return
```

参数顺序必须保持不变。允许在 `run_kernel` 内缓存编译后的 kernel，但不得修改只读输入 tensor，且必须完整写入输出 tensor `y`。
